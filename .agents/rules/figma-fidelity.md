# Rule: Figma Design Fidelity

## Principle
Every UI component, layout container, font size, line height, letter spacing, color, and geometric line detail must be 100% faithful to the designs in the Figma file `design portfolio 2025`.

## Guidelines
1. **Typography**:
   - `DM Sans`: Primary sans-serif font for headings, body copy, and UI text.
   - `Almarai`: Accents, stylized numerals, and geometric labels.
   - `Merriweather`: Light italic editorial notes, captions, and quotes.
   - `Concert One`: Hero display text and stylized branding headers where specified.

2. **Color Palette**:
   - Light Mode:
     - Background: `#FFF7E7` (warm cream)
     - Text Primary: `#0A0F24` (deep ink navy)
     - Text Secondary: `#505050` / `#7C4C4C`
     - Brand Rust / Coral: `#DE4313`
     - Brand Orange: `#F47303` / `#FBBA4B`
     - Brand Teal: `#098B90`
     - Card Backgrounds: `#FCFAF8` / `#FCF7EE` with thin border `#0A0F24` (0.15–0.4 opacity)
   - Dark Mode:
     - Derived directly from `home-defult-new` (`21:899`).

3. **Geometric Details**:
   - Framed borders around sections with decorative corner marks and horizontal dividing lines (`Line 22`, `Line 23`, `Line 30`).
   - Vertical action tabs (`KNOW MORE`, `VIEW ALL WORK`, `VIEW ALL BLOGS`, `GET IN TOUCH`).
   - Section numbers (`01`, `02`, `03`, `04`) in hollow outlined or accent styling.

4. **Asset Integrity**:
   - Always extract real SVG vector data and images from Figma rather than using generic icon libraries or placeholder images.
